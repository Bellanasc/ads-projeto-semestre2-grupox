# 📊 Automação de Estoque — RG MAKE

## 📌 Sobre o projeto

Este projeto tem como objetivo desenvolver uma solução de automação para o controle de estoque da loja **RG MAKE**, buscando otimizar a organização e o gerenciamento das informações relacionadas aos produtos, estoque e faturamento.

Atualmente, a loja enfrenta dificuldades no controle de suas informações devido ao armazenamento manual dos dados em cadernos. Esse método dificulta o acompanhamento da quantidade de produtos disponíveis, o registro de entradas e saídas e o controle do faturamento, podendo ocasionar esquecimentos, falta de produtos para reposição e prejuízos financeiros.

Diante desse cenário, nosso grupo desenvolveu uma solução que automatiza o processo de digitalização, processamento e visualização dos dados, tornando a gestão de estoque mais organizada e eficiente.

## 🎯 Objetivo

Automatizar o controle de estoque da RG MAKE por meio da extração e processamento de informações registradas manualmente, transformando esses dados em informações digitais que auxiliem na tomada de decisões e no gerenciamento da loja.

## ⚙️ Etapas do projeto

O desenvolvimento da solução foi dividido em quatro etapas principais:

1. **Coleta dos dados:** obtenção das informações registradas manualmente nos cadernos da loja.
2. **OCR (Reconhecimento Óptico de Caracteres):** utilização da tecnologia OCR para reconhecer e extrair os textos presentes nas imagens dos registros.
3. **Excel:** organização de todos os dados da loja.
4. **Python:** processamento, organização e tratamento dos dados extraídos, preparando as informações para análise.
5. **Power BI:** criação de dashboards e visualizações para facilitar o acompanhamento das informações e a análise do estoque.

### 🔄 Fluxo de processamento

`Caderno → OCR → Excel→ Python → Power BI`

## 🛠️ Tecnologias utilizadas

- **OCR:** reconhecimento e extração de informações de documentos físicos.
- **Ecxel** organização dos dados
- **Python:** processamento, limpeza e organização dos dados.
- **Power BI:** visualização de dados e criação de dashboards interativos.

## 📈 Resultados esperados

Com a implementação da solução, espera-se reduzir a dependência de registros manuais, melhorar a organização das informações, facilitar o acompanhamento do estoque e proporcionar uma visão mais clara dos dados relacionados aos produtos e ao faturamento da loja.

## 👥 Equipe

Projeto desenvolvido em grupo como parte de um trabalho acadêmico, com foco na aplicação de tecnologias para solucionar problemas reais de gestão empresarial.
